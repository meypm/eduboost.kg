# EduBoost — современная функциональная версия

Сайт полностью на русском языке, с современным дизайном и функционалом платформы.

## Как открыть

1. Распакуйте ZIP.
2. Откройте `index.html` через Chrome.

## Работает без сервера

Все данные сохраняются в браузере через localStorage.

## Функции

- регистрация пользователей
- панель управления
- электронный журнал
- группы АСУо(9кл)-1-24, 2-24, 3-24, 4-24, 5-24
- отметки посещаемости + / н
- автоматический подсчет н/б
- добавление студентов
- добавление даты занятия
- оценки / GPA
- задания
- документы
- финансы
- мотивация и баллы
- CSV экспорт
- мобильная адаптация


## Уникальный логотип

Добавлены файлы:

- `logo-eduboost.svg` — основной логотип сайта
- `favicon.svg` — иконка вкладки браузера
- `logo-preview.html` — страница предпросмотра логотипа

Идея логотипа: открытая книга + рост/boost + цифровые пиксели + буквы E/B.


## Добавлена игровая система EduBoost

В модуле `Игра / Мотивация` теперь есть:

- автоматический расчет баллов за посещаемость;
- бонус за отсутствие пропусков;
- баллы за хорошие оценки;
- быстрые начисления баллов;
- уровни: Beginner, Active Student, Smart Student, EduBoost Leader;
- достижения / бейджи;
- рейтинг студентов;
- еженедельные миссии;
- магазин подарков;
- обмен баллов на подарки;
- история обмена.


## Добавлена главная страница сайта
